This group aims to create a learning source for subject in Algorithm, Data Structure, and Connectionist AI. 
<br/> Perquisite knowledges required for this course is basic high school mathematical skills.  <br/> We use AI to research the topics we need to cover with the addition of fact checking with source that the AI sourced from.

## Chapter Topics
- Data Structure
  - Introduction to Data Structures
    - Why is Data Structure needed?
    - Examples of real-life application
    - Data vs Data Structures.
  - Fundamental of Abstract Data Types(ADTs)
    - Linear Structures
    - Priority Queus
    - Maps & Sets
    - Data Structures for strings
- Algorithm
  - Foundation of Algorithmic Analysis
    - Asymptotic Notation
    - Recurrence Relations
    - Amortized Analysis
  - Core Algorithm Design Paradigms
    - Divide and Conquer
    - Greedy Algorithm
    - Backtracking & Branch-and-Bound
    - Randomised Algorithms
    - Approximation & NP-Hardness
  - Graph Algorithms
    - Graph Traversal
    - Shortest Paths
    - Minimum Spanning Trees
    - Network Flow
- Connectionist AI
  - The "Symbolic vs Connectionist" Paradigm
  - Biological Inspiration and The Perceptron
    - The Biological Anatomy of a Neuron and The Neuron Model
    - Learning Rule
  - Core Learning Mechanism
    - Supervised learning
    - Semi-supervised learning
    - Backpropagation
    - Gradient Descent & Optimisation
    - Loss Functions & Regularisations 
  - Major Network Architecutures
    - Feedforward Network (MLPs)
    - Convolutional Neural Networks(CNNs)
    - Recurrent Neural Network(RNNs)
    - Transformers
  - Unsupervised and Generative Learning
    - Clustering & Dimensionality Reduction
    - Autoencoders
    - Generative Adversarial Networks(GANs)
  - Reinfored Learning(RL)
    - The RL Framework
    - Reep 
  - AI Ethics, Limitations, and Explanaible AI
    - The "Black Box" problem / Interpretability
    - Bias and Fairness
    - Overfitting and Generalisation

- ### [PPT Document](https://github.com/Jrmy-y/Wahaha-Project/tree/4c48305c0828f434aba2b5a0fc3a6c32a8164268/Learning%20Materials%20/PPT%20Document)
